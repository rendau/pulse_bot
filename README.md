# pulse_bot

Telegram-бот для разговора об инфраструктуре поверх MCP-сервера pulse.
Что строим и принятые решения — [docs/bot-spec.md](docs/bot-spec.md).

### Сборка и запуск

```
make build
go run ./cmd/.
```

Переменные окружения — `internal/config/config.go`, пример — `.env.example`.

### Бот в группе

1. В @BotFather: `/setprivacy` → бот → **Disable**. С включённым режимом приватности Telegram
   не присылает боту упоминания `@бот` — доходят только команды `/cmd@бот` и ответы на его
   сообщения. Остальную переписку группы бот пропускает сам.
2. Добавить бота в группу. Если бот уже был в группе до смены режима — удалить и добавить
   заново: новый режим действует только после повторного добавления.
3. Дописать id группы (с минусом) в `TELEGRAM_ALLOWED_CHAT_IDS` в kusec. Сообщения из
   неразрешённых групп бот отбрасывает молча.

Проверка: `/help@<бот>` в группе. Бот молчит — не тот id (группа могла стать супергруппой,
тогда id вида `-100…`); отвечает на команду, но не на `@бот` — режим приватности не выключен.
